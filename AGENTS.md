# Documentation

Use ASD-STE100 Simplified Technical English as the style guide.

- Use short sentences and plain words.
- Use the same term for the same item.
- Use the active voice. Name the person, tool, or system that does the action.
- Use numbered steps for procedures. Put one action in each step.
- Use short headings, lists, and code blocks to help readers find information.
- Keep command names, file paths, and interface labels exact.
